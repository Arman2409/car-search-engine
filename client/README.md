# React + Vite + TypeScript + Tailwind + SCSS app blueprint

## Setup
1. Install dependencies: `bun install` or `npm install`
2. Run dev server: `bun dev` or `npm run dev`
3. Open `http://localhost:5173` in your browser.

## Structure
- `src/components/`: Reusable components (`shared/`) and page-specific ones (`pages/`).
- `src/styles/`: SCSS variables (`colors.scss`) and Tailwind setup.
- `src/types/`: TypeScript definitions.

## Notes
- Material UI for UI components library.
- Tailwind CSS for styling, with SCSS for custom variables.
